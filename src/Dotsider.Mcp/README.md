# Dotsider.Mcp

MCP server for .NET assembly analysis. Works in two modes:

- **Direct mode** — pass an `assemblyPath` to analyze any `.dll` or `.exe` on disk
- **Session mode** — pass a `sessionId` (PID) to query a running dotsider TUI instance over its Unix domain socket

Most tools accept either parameter. Session-only tools (navigation, tracing) require a running instance.

## Setup

```json
{
  "mcpServers": {
    "dotsider": {
      "command": "dotsider-mcp"
    }
  }
}
```

## Tools

### Assembly

| Tool | Description |
|------|-------------|
| `get_assembly_info` | Name, version, framework, architecture, member counts |
| `list_types` | Type definitions with optional name filter and limit |
| `list_methods` | Method definitions with optional type/name filter |
| `find_members` | Search types, methods, and member refs by query string |

### Metadata

| Tool | Description |
|------|-------------|
| `get_pe_headers` | PE machine type, subsystem, characteristics |
| `get_clr_header` | Runtime version, flags, entry point token |
| `get_sections` | PE sections with virtual address and size |
| `get_custom_attributes` | Custom attributes (filters compiler-generated by default) |
| `get_resources` | Manifest resources |
| `resolve_token` | Resolve a metadata token to a human-readable name |

### IL

| Tool | Description |
|------|-------------|
| `disassemble_method` | IL bytecode for a specific method |
| `search_il_opcodes` | Find methods containing a specific opcode (e.g., `calli`, `newobj`) |

### Size

| Tool | Description |
|------|-------------|
| `get_size_breakdown` | Hierarchical size tree: namespace > type > method |
| `get_largest_methods` | Top methods by IL byte size |

### Strings

| Tool | Description |
|------|-------------|
| `extract_strings` | User strings, metadata strings, and raw binary strings |

### Dependencies

| Tool | Description |
|------|-------------|
| `get_assembly_refs` | Assembly references with version and public key token |
| `get_dependency_graph` | Nodes and edges for visualization |
| `get_type_refs` | Types imported from other assemblies |

### Diff

| Tool | Description |
|------|-------------|
| `diff_assemblies` | Compare two assemblies: added/removed/changed types, methods, refs |

### NuGet

| Tool | Description |
|------|-------------|
| `analyze_nupkg` | Package metadata and DLL listing from a `.nupkg` file |

### Sessions

| Tool | Description |
|------|-------------|
| `discover_dotsider_sessions` | Scan for running instances, probe each via UDS |
| `get_session_info` | Assembly info and current view from a running instance |

### Navigation (session-only)

| Tool | Description |
|------|-------------|
| `get_current_view` | Active tab, loaded assembly, trace state |
| `navigate_to` | Switch to a specific tab by ID |
| `capture_screen` | Capture TUI screen as text, ANSI, HTML, or SVG |

### Tracing (session-only)

| Tool | Description |
|------|-------------|
| `start_trace` | Launch and monitor the loaded assembly |
| `stop_trace` | Stop the active trace session |
| `get_trace_events` | JIT, GC, exception events with optional category filter |
| `get_trace_counters` | Latest performance counter snapshot |
| `get_process_output` | Captured stdout/stderr from the traced process |

## Prompts

| Prompt | Description |
|--------|-------------|
| `security_audit` | Step-by-step security audit: dangerous APIs, hardcoded secrets, IL patterns |
| `api_review` | Public API surface review: naming, nullability, async patterns |
| `breaking_change_detection` | Compare two assembly versions for binary/source/behavioral breaks |
| `dependency_health` | Dependency graph analysis: diamond deps, unused refs, version risks |
